# Code review addendum: data integrity pass, 2026-11-13

The owner's rule: no figure on the site may be invented. This pass went through the desks
added in the "Phases 9 to 18" commit (`b5a258d`) and found that most of them served numbers
that were typed into the code or generated by a formula, several under an "[ACTUAL FILING]"
badge. Each desk below was confirmed in the code before it was changed. Findings continue
from F-75.

There are now two states a desk can be in: it reads a real source, or it refuses and says
which source it is waiting for (`backend/app/not_connected.py`). There is no third state in
which stored sample numbers are shown.

## Rebuilt on real data

| ID | Desk | What it did | What it does now |
|---|---|---|---|
| F-76 | Tear sheet (`/company/X/tear`) | Two hand-entered companies; every other symbol got a price, ISIN, executives, ten years of financials and peers generated from the letters of the ticker. Sample analyst notes were seeded for three companies. The page printed fixed growth rates for every company. | `services/tear_sheet_live.py` assembles the sheet from the same routes as the company page. Missing figures print as a dash. No notes are seeded. |
| F-77 | Valuation lab (`/company/X/valuation`) | The page used Reliance's cash flow, share count and debt for every symbol. The backend had seven hand-entered companies and generated the rest from the ticker's letters. The reverse DCF was an approximation formula. | `services/valuation_inputs.py` reads price, shares, cash, debt and trailing free cash flow, fits beta by regression against the Nifty 50, and labels growth and discount inputs as assumptions. Lenders and companies with negative free cash flow are refused with the reason. The reverse DCF is solved exactly. |
| F-78 | Corporate network (`/company/X/network`) | Four hand-compiled companies; every other symbol got invented subsidiaries, suppliers and customers. | A company not on file returns 404 with an explanation. The hand-compiled entries are served with a source line that says they are hand-compiled and not machine-checked. |
| F-79 | SME board (`/sme`) | A hand-entered list of listings and IPOs with stale prices, fictional issues and grey-market premiums; the page was hardcoded and never called the backend. | `services/sme_live.py` reads NSE's traded list (series SM and ST) and the IPO pipeline's SME segment. Grey-market premium is gone. BSE SME, fundamentals and migration eligibility are declared as not covered. |
| F-80 | Copilot | Ten hardcoded company "dossiers" and a generic one for everything else; canned analyses with fixed numbers for any symbol. | Answers are built from the tear-sheet figures (`lib/copilot/brief.ts`). The AI mode is grounded in the same figures and told to use no others. An unknown symbol gets "no data". |
| F-81 | Risk lab (`/risk-lab`) | Crisis drawdowns, per-stock "crisis betas" and factor loadings were typed in; factor returns and the backtest price path were sine waves; the page was hardcoded. | `services/risk_lab.py` holds only the dates of each crisis. Index and holding moves are computed from recorded daily closes; a holding not listed then is estimated from its regression beta and marked. The backtest runs on the symbol's real closes. Multi-factor exposures are replaced by single-index regressions, because no free source publishes Indian factor returns. |
| F-82 | Excel endpoints (`/api/v1/xls/*`) | Six hardcoded quotes, a fixed price for every other symbol, and sine-wave history. | Live quote, valuation and candles from the data service. |
| F-83 | Participant open interest (`/participant-oi`) | A stored table described as NSE's report. | Parsed from NSE's daily `fao_participant_oi` file; no stored copy. |
| F-84 | Earnings implied moves | Compared the implied move with a "historical average" that was a constant, and returned field names the page did not read, so the desk showed nothing. | The comparison is removed (the label describes the implied move's size only) and the fields match the page. |

## Smaller fixes

- F-91: the surveillance desk no longer seeds stored rows when NSE's lists cannot be fetched.
- F-92: the paper-trading account starts as cash only. The order ticket takes any ticker and
  can load the delayed market price. The "broker gateway" tab, which listed four brokers as
  connected with ping times, now says no broker is connected.
- F-93: the portfolio page no longer falls back to a stored analysis with invented prices.
- F-94: the company quote is no longer served from Next's timed cache, which could show a
  price several days old on the first request after a quiet period.
- F-95: `/api/risk-lab` and `/api/sectors` were not reachable under `/api/v1`, where the site
  calls them.
