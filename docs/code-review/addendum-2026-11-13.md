# Code review addendum: security pass, 2026-11-13

A security review of the whole site (Next.js front end, FastAPI data service, dependencies,
deploy scripts) against commit `fecc1fa`. Findings continue the numbering of the earlier
reviews. Every finding below was confirmed in the code and fixed in this pass unless marked
otherwise. Regression tests: `backend/tests/test_security_hardening.py` and
`lib/api/request-guards.test.ts`.

## Fixed

| ID | Severity | Finding | Fix |
|---|---|---|---|
| F-57 | High | The analyzer proxy (`app/api/analyzer/[...path]/route.ts`) attached the service bearer token to POST and DELETE requests from any origin, so a page on another site could start, cancel or delete analysis runs. | Cross-site requests are refused (Origin and Sec-Fetch-Site), writes are rate-limited per caller, and the error body no longer carries the upstream exception. |
| F-58 | High | JSON-LD was written with `JSON.stringify` into an inline `<script>`. A scraped company name or summary containing `</script>` would run as markup. The company route also accepted any string as a symbol. | `lib/json-ld.ts` escapes `<`, `>`, `&` and the line separators. `app/company/[symbol]/layout.tsx` returns 404 for anything that is not ticker-shaped. |
| F-59 | High | The Excel endpoints (`/api/v1/xls/quote`, `/api/v1/xls/hist`) echoed an unvalidated `symbol` into a CSV cell and the `Content-Disposition` header (formula injection, header parameter injection). `days` accepted NaN and negatives. | Symbol must be ticker-shaped and start with a letter or digit, the file name is sanitised, `days` is clamped to 1..365. |
| F-60 | High | With `ARTHDEX_API_TOKEN` unset the data service accepted every request, including orders, analyzer runs, notes, cache expiry and feed repair, from anywhere. | Without a token the service takes state-changing requests from the local machine only. A deployment whose gateway authenticates callers sets `ARTHDEX_ALLOW_OPEN_WRITES=1` (see `docs/deployment.md`). |
| F-61 | High | Paper trading took `quantity` and `price` from a raw dict. A BUY with a negative quantity credited cash, NaN or infinity corrupted the account, and the shared account had no lock. | Typed request models with bounds, the same checks inside the engine, a lock around the account, a capped order history and collision-free order ids. |
| F-62 | Medium | Copilot route: no origin check or rate limit (anyone could spend the platform model quota), unbounded prompt, API key in the URL query string, instructions concatenated into the user turn, user key kept in `localStorage`. | Same-site only, 15 requests a minute per caller, 4,000 character prompt cap, key sent in the `x-goog-api-key` header, instructions moved to `systemInstruction`, role checked against the known list, 30 s timeout, user key kept in `sessionStorage`. |
| F-63 | Medium | The Content-Security-Policy allowed `unsafe-eval` and connections to any origin over any scheme. | Production drops `unsafe-eval`, `connect-src` is `'self'`, and `object-src 'none'`, `frame-src`, `worker-src`, `media-src` and `upgrade-insecure-requests` are set. `X-Powered-By` is off and the obsolete `X-XSS-Protection` header is gone. |
| F-64 | Medium | `/docs` and `/openapi.json` were exempt from the token and always served. | Served only in local development (no token) or with `ARTHDEX_ENABLE_DOCS=1`, and no longer exempt from the token. |
| F-65 | Medium | The analyzer report was served with `sandbox allow-same-origin allow-scripts`, which gives its scripts the API's origin. The report embeds scraped text. | `allow-same-origin` removed, matching the front-end proxy. |
| F-66 | Medium | Unbounded model inputs: DCF projection years, growth and discount rates; backtest look-back periods (a zero period raised `ZeroDivisionError`). | Bounds on every numeric field; invalid backtest periods fall back to 20/50. |
| F-67 | Medium | `POST /api/v1/health/feeds/run` probed about twenty upstreams on every call with no cooldown. | A 60 second cooldown returns the last result. |
| F-68 | Medium | Research notes had no length limits and an unbounded in-memory store; no route limited request body size. | Length and count limits on every field, 50 notes per company and 500 companies, and a 1 MB request body limit across the service. |
| F-69 | Medium | `deploy/huggingface/push.ps1` copied `backend/` to the Space without excluding `app_data`, SQLite files or `.env*`. | Those, key files and tool caches are excluded. |
| F-70 | Low | 5xx responses carried exception text (98 `detail=f"...{exc}"` sites; three front-end proxies returned `err.message`). | One exception handler logs the text and returns only the leading description; the proxies return fixed messages. |
| F-71 | Low | The cache-refresh Server Action accepted any path and cache prefix from the client. | Path shape, an allow-list of prefixes, a ticker-shaped symbol and 12 calls a minute per caller. |
| F-72 | Low | `/api/quote`, `/api/orderflow` and `/api/forecast/scenarios` did not send the service token, so they failed once a token was configured. Forecast forwarded unvalidated `capital`, `risk_pct` and `exchange`. | Token header added; the three parameters are validated. |
| F-73 | Low | A non-ASCII `Authorization` header made `hmac.compare_digest` raise (500). | Compared as bytes. |
| F-74 | Low | One research-note URL interpolated the symbol unencoded; the screener industry path was joined to the host unchecked. | Encoded; the path must be a plain site-relative path. |
| F-75 | High (dev only) | Dependencies: `postcss` 8.5.1 (XSS in stringifier, file read), and `certifi`, `filelock`, `opentelemetry-api`, `setuptools` (18 advisories). | Bumped to patched versions. `pip-audit` reports none; `npm audit --omit=dev` reports none. |

## Open

- **`unsafe-inline` in `script-src`.** Next's inline bootstrap scripts need it unless every page
  is rendered per request with a nonce. Worth doing once the pages that can be static are
  settled; the JSON-LD escape (F-58) closes the one injection path found.
- **`minimatch` in the ESLint toolchain** (7 moderate advisories, one root cause). Development
  only; the patched release is a major version `typescript-eslint` does not accept yet.
- **Rate limits are per process.** `lib/api/request-guards.ts` keeps counters in memory, which
  bounds one server instance. A gateway limit is still needed for a multi-instance deployment.
- **`backend/ceia/report.py` `_stat`** writes values into the report without escaping. The
  report now runs in an opaque origin (F-65), so the effect is contained to the report frame.
- **CI actions** are pinned to tags, not commit hashes.

## Checked and found sound

CORS (explicit origins, no credentials); token comparison is constant-time; no hardcoded
secrets in the tree or in git history; `.env.local` is ignored; no `NEXT_PUBLIC_` variable
carries a secret; no `eval`, `pickle`, `yaml.load` or shell execution on request data; the
analyzer proxy forwards only allow-listed paths; HSTS, `nosniff`, frame denial, referrer and
permissions policies are set; the Hugging Face image runs as a non-root user.
