# =============================================================================
#  Arthdex data service - Python dependencies
#  File: backend/requirements.txt
# =============================================================================
#
#  Tested with : Python 3.14.6 on Windows 11 (64-bit), pip 26.2
#  Python      : 3.12 or newer. numpy 2.5 and scipy 1.18 require it, and networkx
#                excludes exactly 3.14.1. Anything other than 3.14.6 is untested.
#  Install     : python -m pip install -r requirements.txt     (run inside backend/, in a venv)
#  Dev tools   : python -m pip install -r requirements-dev.txt (ruff; adds this file)
#  Size        : about 1.1 GB installed, most of it torch (about 0.4 GB without it). See "Lighter install" below.
#
#  How this file is organised
#    1. Direct dependencies - what the code imports, with the reason.
#    2. Optional extras     - commented out; enable only if you use that feature.
#    3. Resolved transitive dependencies - pinned so every machine gets the same
#       versions. Each line says which package pulls it in.
#
#  Lighter install (no language models)
#    The event-impact engine falls back to a word-list sentiment model when torch /
#    transformers are missing (it says so in the run log) and skips emotion tags.
#    Everything else on the site works. To skip them, delete the "torch" and
#    "transformers" lines in section 1d and every line tagged [ml-only] in section 3.
#    That cuts the install from about 1.1 GB to about 0.4 GB. This variant was
#    installed and unit-tested on a clean machine.
#
#  Updating pins
#    Install into a clean venv, run the unit tests and the site, then regenerate with
#    "python -m pip freeze" and re-annotate. Do not edit pins by hand.
#
#  Not installed by this file
#    * Node packages (the website)     -> package.json / package-lock.json (npm ci)
#    * Playwright browsers (PDF export) -> see section 2
# =============================================================================
