# Bundled fonts

Built on 3 November 2026 from the variable sources in [google/fonts](https://github.com/google/fonts) with fontTools: subset to Latin and Latin Extended (which includes the rupee sign, U+20B9), Devanagari for Noto Sans Devanagari, and instanced to the weights the site uses. All are under the SIL Open Font License 1.1, which permits bundling.

| File | Family | Weights |
|---|---|---|
| geist.woff2 | Geist | 100 to 900 |
| geist-mono.woff2 | Geist Mono | 100 to 900 |
| funnel-display.woff2 | Funnel Display | 500 to 700 (no rupee glyph in the source font) |
| source-serif-4-bold.woff2 | Source Serif 4 | 700, default optical size |
| noto-sans-devanagari.woff2 | Noto Sans Devanagari | 400 to 600, normal width |
